# Teman Pemula Technocore

Panduan komunitas tidak resmi untuk memahami apa yang boleh dibagikan, apa yang harus disimpan, dan apa yang dicatat saat mengirim karya. Rujukan proyek: [@flop_labs](https://x.com/flop_labs).

**Status:** Proyek komunitas yang dibuat dengan bantuan AI. Belum diajukan ke Technocore.

**DID publik kontributor:** belum dicantumkan.

## Coba alatnya

Buka `index.html` di browser. Tidak perlu instalasi, login, wallet, atau sambungan internet. Pemeriksa hanya membaca format Base58 dan kode Ed25519 pada DID yang dimasukkan. Hasilnya tidak memverifikasi kepemilikan atau tanda tangan. Tidak ada penyimpanan, pelacakan, maupun pengiriman input.

## Alur kontribusi

1. Di [onboarding Technocore](https://technocore-start.vercel.app/), simpan dua hal secara terpisah: `identity.pem` terenkripsi dan passphrase. Keduanya tidak boleh masuk README atau repositori.
2. Tambahkan **DID publik saja** ke README. Personalisasi kontribusi dengan hal nyata yang kamu pelajari dan periksa sendiri. Draf kode dan panduan ini disiapkan dengan bantuan AI; jangan mengaku seluruh draf dikerjakan sendiri. Jika syarat “I made it myself” tidak mengizinkan karya berbantuan AI, gunakan alat ini sebagai referensi, bukan sebagai entri.
3. Jika memenuhi aturan, terbitkan folder ini sebagai repositori publik. Uji tautan tanpa login. Pilih **Kode atau alat**, lalu masukkan URL repositori publik pada langkah 4.
4. Untuk catatan karya, kalimat topik yang dapat disesuaikan: “Membedakan DID publik, file identitas, dan passphrase; mengecek format DID tanpa mengirim data.” Tinjau dan tanda tangani sendiri pada langkah 5. Simpan nomor urut dari lobi dan dari catatan karya.

Rujukan teknis: [W3C DID Core](https://www.w3.org/TR/did-1.0/) dan [did:key](https://w3c-ccg.github.io/did-key-spec/). Tidak ada klaim hadiah, airdrop, atau afiliasi resmi.
